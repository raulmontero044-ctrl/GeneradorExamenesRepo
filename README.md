# GeneradorExamenesRepo

Generador de exámenes tipo test (40 preguntas, 5 por tema) de **Programación** (temas 8, 9, 10 y 12) y **Desarrollo Web en Entorno Servidor** (temas 1 a 4), basado exclusivamente en el temario de [cesguiro.es](https://cesguiro.es/doku.php/clase/daw/start), construido con skills y subagentes de Claude Code.

## Inicio rápido

1. Abre Claude Code en este repositorio.
2. Ejecuta `/do-examen` y elige una operación: generar examen, actualizar wiki o revisar el banco.
3. Para hacer un examen: `npm run servidor` y abre la URL que indique.
